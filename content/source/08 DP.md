# Dynamic Programming — Problem Set (C++)

Problems grouped by sub-pattern so the underlying trick is easy to spot and reuse.

## 1. Linear / 1D DP (Fibonacci-style)

### 1.1 Climbing Stairs
**LeetCode:** https://leetcode.com/problems/climbing-stairs/

You can climb 1 or 2 steps at a time. Count the distinct ways to reach step `n`.

**Approach:** `dp[i] = dp[i-1] + dp[i-2]` — same recurrence as Fibonacci. Only the last two states matter, so roll the array into two variables.

```cpp
class Solution {
public:
    int climbStairs(int n) {
        if (n <= 1) return 1;
        int prev2 = 1, prev1 = 1; // ways to reach step 0 and step 1
        for (int i = 2; i <= n; i++) {
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
};
```
**Time:** O(n) **Space:** O(1)

---

### 1.2 House Robber
**LeetCode:** https://leetcode.com/problems/house-robber/

Given house values in a line, rob houses to maximize total money without robbing two adjacent houses.

**Approach:** At each house, either skip it (`dp[i-1]`) or rob it plus the best from two houses back (`dp[i-2] + nums[i]`).

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0, prev1 = 0; // dp[i-2], dp[i-1]
        for (int num : nums) {
            int cur = max(prev1, prev2 + num); // skip house i or rob it
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
};
```
**Time:** O(n) **Space:** O(1)

---

### 1.3 House Robber II
**LeetCode:** https://leetcode.com/problems/house-robber-ii/

Same as House Robber, but houses are arranged in a circle (first and last are adjacent).

**Approach:** The circular constraint only matters for the first/last pair. Run linear House Robber twice — once excluding the last house, once excluding the first — and take the max.

```cpp
class Solution {
public:
    int robLine(vector<int>& nums, int start, int end) {
        int prev2 = 0, prev1 = 0;
        for (int i = start; i <= end; i++) {
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        // Case 1: exclude last house | Case 2: exclude first house
        return max(robLine(nums, 0, n - 2), robLine(nums, 1, n - 1));
    }
};
```
**Time:** O(n) **Space:** O(1)

### 1.4 Decode Ways
**LeetCode:** https://leetcode.com/problems/decode-ways/

A digit string maps to letters A–Z via 1–26. Count the number of ways to decode it.

**Approach:** `dp[i]` = ways to decode the first `i` characters. Add `dp[i-1]` if the last single digit is valid (1–9), and `dp[i-2]` if the last two digits form a valid number (10–26).

```cpp
class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();
        if (n == 0 || s[0] == '0') return 0;
        int prev2 = 1, prev1 = 1; // dp[0] = 1 (empty prefix), dp[1] = 1
        for (int i = 2; i <= n; i++) {
            int cur = 0;
            int oneDigit = s[i - 1] - '0';
            int twoDigit = (s[i - 2] - '0') * 10 + oneDigit;
            if (oneDigit >= 1) cur += prev1;                     // single digit decode
            if (twoDigit >= 10 && twoDigit <= 26) cur += prev2;  // two digit decode
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
};
```
**Time:** O(n) **Space:** O(1)

## 2. Grid / 2D Path DP

### 2.1 Unique Paths
**LeetCode:** https://leetcode.com/problems/unique-paths/

Count paths from the top-left to bottom-right of an `m x n` grid, moving only right or down.

**Approach:** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`. Roll the grid into a single 1D row since each row only depends on the previous one.

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<int> dp(n, 1); // first row: exactly 1 way to reach each cell
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j - 1]; // dp[j] currently holds dp[i-1][j]
            }
        }
        return dp[n - 1];
    }
};
```
**Time:** O(m·n) **Space:** O(n)

---

### 2.2 Unique Paths II
**LeetCode:** https://leetcode.com/problems/unique-paths-ii/

Same as Unique Paths, but some cells are obstacles (marked `1`) and cannot be entered.

**Approach:** Same recurrence, but force `dp[j] = 0` whenever the current cell is an obstacle.

```cpp
class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<long> dp(n, 0);
        dp[0] = (grid[0][0] == 0) ? 1 : 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    dp[j] = 0; // obstacle blocks this cell entirely
                } else if (j > 0) {
                    dp[j] += dp[j - 1]; // add paths coming from the left
                }
            }
        }
        return (int)dp[n - 1];
    }
};
```
**Time:** O(m·n) **Space:** O(n)

---

### 2.3 Minimum Path Sum
**LeetCode:** https://leetcode.com/problems/minimum-path-sum/

Find the path from top-left to bottom-right that minimizes the sum of numbers along it (right/down moves only).

**Approach:** `dp[j] = grid[i][j] + min(dp[j] /*from top*/, dp[j-1] /*from left*/)`.

```cpp
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<int> dp(n, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (j == 0) dp[j] = dp[j] + grid[i][j];          // only from top
                else        dp[j] = grid[i][j] + min(dp[j], dp[j - 1]); // min(top, left)
            }
        }
        return dp[n - 1];
    }
};
```
**Time:** O(m·n) **Space:** O(n)

## 3. 0/1 Knapsack Pattern

*Trick: iterate the sum/capacity dimension **backwards** so each item is used at most once.*

### 3.1 Partition Equal Subset Sum
**LeetCode:** https://leetcode.com/problems/partition-equal-subset-sum/

Determine whether an array can be split into two subsets with equal sum.

**Approach:** Equal partition exists iff some subset sums to `total/2`. Classic 0/1 knapsack reachability check.

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        if (total % 2 != 0) return false;
        int target = total / 2;
        vector<bool> dp(target + 1, false);
        dp[0] = true; // sum 0 is always achievable
        for (int num : nums) {
            for (int s = target; s >= num; s--) { // backwards: use num at most once
                dp[s] = dp[s] || dp[s - num];
            }
        }
        return dp[target];
    }
};
```
**Time:** O(n·sum) **Space:** O(sum)

---

### 3.2 Target Sum
**LeetCode:** https://leetcode.com/problems/target-sum/

Assign `+` or `-` to each number so the expression evaluates to `target`. Count the number of ways.

**Approach:** Let `P` be the sum of numbers assigned `+`. Then `P - (total - P) = target`, so `P = (total + target) / 2`. Count subsets summing to `P` (0/1 knapsack, counting ways instead of just reachability).

```cpp
class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        if (abs(target) > total || (total + target) % 2 != 0) return 0;
        int P = (total + target) / 2; // subset getting '+' must sum to P
        vector<int> dp(P + 1, 0);
        dp[0] = 1;
        for (int num : nums) {
            for (int s = P; s >= num; s--) {
                dp[s] += dp[s - num]; // count ways, not just reachability
            }
        }
        return dp[P];
    }
};
```
**Time:** O(n·P) **Space:** O(P)

## 4. Unbounded Knapsack Pattern

*Trick: iterate the sum dimension **forwards** so each item can be reused any number of times.*

### 4.1 Coin Change
**LeetCode:** https://leetcode.com/problems/coin-change/

Given unlimited coins of given denominations, find the fewest coins needed to make up `amount`.

**Approach:** `dp[a]` = min coins to make amount `a`. For each coin, `dp[a] = min(dp[a], dp[a-coin] + 1)`.

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, INT_MAX);
        dp[0] = 0;
        for (int a = 1; a <= amount; a++) {
            for (int coin : coins) {
                if (coin <= a && dp[a - coin] != INT_MAX) {
                    dp[a] = min(dp[a], dp[a - coin] + 1);
                }
            }
        }
        return dp[amount] == INT_MAX ? -1 : dp[amount];
    }
};
```
**Time:** O(amount·coins) **Space:** O(amount)

---

### 4.2 Coin Change II
**LeetCode:** https://leetcode.com/problems/coin-change-ii/

Count the number of distinct **combinations** (order doesn't matter) of coins that sum to `amount`.

**Approach:** Put the coin loop **outside** the amount loop. This ensures combinations are counted once, not once per ordering (permutation).

```cpp
class Solution {
public:
    int change(int amount, vector<int>& coins) {
        vector<int> dp(amount + 1, 0);
        dp[0] = 1; // one way to make amount 0: use nothing
        for (int coin : coins) {
            for (int a = coin; a <= amount; a++) { // coin outer -> combinations, not permutations
                dp[a] += dp[a - coin];
            }
        }
        return dp[amount];
    }
};
```
**Time:** O(amount·coins) **Space:** O(amount)

## 5. Longest Common Subsequence Family (Two Strings)

### 5.1 Longest Common Subsequence
**LeetCode:** https://leetcode.com/problems/longest-common-subsequence/

Find the length of the longest subsequence common to two strings.

**Approach:** `dp[i][j]` = LCS of `text1[0..i)` and `text2[0..j)`. Match extends diagonally; mismatch takes the best of dropping a char from either string.

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size(), n = text2.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1[i - 1] == text2[j - 1])
                    dp[i][j] = dp[i - 1][j - 1] + 1;              // extend match
                else
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);   // skip a char
            }
        }
        return dp[m][n];
    }
};
```
**Time:** O(m·n) **Space:** O(m·n) (reducible to O(n))

---

### 5.2 Edit Distance
**LeetCode:** https://leetcode.com/problems/edit-distance/

Minimum operations (insert, delete, replace) to convert `word1` into `word2`.

**Approach:** Same grid shape as LCS. On a match, carry the diagonal value forward; on a mismatch, take `1 + min(replace, delete, insert)`.

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int m = word1.size(), n = word2.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i <= m; i++) dp[i][0] = i; // delete all of word1
        for (int j = 0; j <= n; j++) dp[0][j] = j; // insert all of word2
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1]; // no operation needed
                } else {
                    dp[i][j] = 1 + min({dp[i - 1][j - 1],  // replace
                                         dp[i - 1][j],      // delete
                                         dp[i][j - 1]});    // insert
                }
            }
        }
        return dp[m][n];
    }
};
```
**Time:** O(m·n) **Space:** O(m·n)

## 6. Longest Increasing Subsequence Family

### 6.1 Longest Increasing Subsequence
**LeetCode:** https://leetcode.com/problems/longest-increasing-subsequence/

Find the length of the longest strictly increasing subsequence in an array.

**Approach:** Classic DP is `dp[i] = 1 + max(dp[j])` for `j < i` with `nums[j] < nums[i]` — O(n²). The faster version maintains a `tails` array (smallest possible tail for each subsequence length) and binary searches it — O(n log n).

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails; // tails[i] = smallest tail of an increasing subsequence of length i+1
        for (int num : nums) {
            auto it = lower_bound(tails.begin(), tails.end(), num);
            if (it == tails.end()) tails.push_back(num); // extends longest subsequence so far
            else *it = num;                               // keeps tail as small as possible
        }
        return tails.size();
    }
};
```
**Time:** O(n log n) **Space:** O(n)

## 7. Palindrome DP

*Trick: fill the DP table by increasing substring length, since `dp[i][j]` depends on the shorter inner substring `dp[i+1][j-1]`.*

### 7.1 Longest Palindromic Substring
**LeetCode:** https://leetcode.com/problems/longest-palindromic-substring/

Find the longest substring of `s` that is a palindrome.

**Approach:** `dp[i][j]` = true if `s[i..j]` is a palindrome, i.e. `s[i]==s[j]` and the inside `s[i+1..j-1]` is also a palindrome (or too short to matter).

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        if (n == 0) return "";
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        int start = 0, maxLen = 1;
        for (int i = 0; i < n; i++) dp[i][i] = true; // every single char is a palindrome
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s[i] == s[j] && (len == 2 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    if (len > maxLen) { maxLen = len; start = i; }
                }
            }
        }
        return s.substr(start, maxLen);
    }
};
```
**Time:** O(n²) **Space:** O(n²)

### 7.2 Palindromic Substrings
**LeetCode:** https://leetcode.com/problems/palindromic-substrings/

Count the total number of palindromic substrings in `s`.

**Approach:** Same table as above — just count every cell that evaluates to true instead of tracking the longest.

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        int n = s.size(), count = 0;
        vector<vector<bool>> dp(n, vector<bool>(n, false));
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (s[i] == s[j] && (len <= 2 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    count++;
                }
            }
        }
        return count;
    }
};
```
**Time:** O(n²) **Space:** O(n²)

### 7.3 Longest Palindromic Subsequence
**LeetCode:** https://leetcode.com/problems/longest-palindromic-subsequence/

Find the length of the longest **subsequence** (not necessarily contiguous) of `s` that is a palindrome.

**Approach:** Interval DP: `dp[i][j] = dp[i+1][j-1] + 2` if `s[i]==s[j]`, else `max(dp[i+1][j], dp[i][j-1])`. (Equivalently, `LCS(s, reverse(s))`.)

```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1; // single character is a palindrome of length 1
            for (int j = i + 1; j < n; j++) {
                if (s[i] == s[j]) dp[i][j] = dp[i + 1][j - 1] + 2; // include both ends
                else               dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]); // drop one end
            }
        }
        return dp[0][n - 1];
    }
};
```
**Time:** O(n²) **Space:** O(n²)

## 8. Interval DP (Matrix-Chain style)

*Trick: choose the "last operation" (last split point / last balloon burst) inside an interval, and combine the two resulting sub-intervals.*

### 8.1 Burst Balloons
**LeetCode:** https://leetcode.com/problems/burst-balloons/

Bursting a balloon gives `left * current * right` coins (of the currently remaining balloons). Maximize total coins from bursting all balloons.

**Approach:** Think in reverse: instead of "which balloon to burst first," decide "which balloon to burst **last**" within an interval `(l, r)`. Pad the array with virtual balloons of value 1 on both ends.

```cpp
class Solution {
public:
    int maxCoins(vector<int>& nums) {
        int n = nums.size();
        vector<int> balloons(n + 2, 1); // padded with virtual balloons of value 1
        for (int i = 0; i < n; i++) balloons[i + 1] = nums[i];

        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
        for (int len = 1; len <= n; len++) {           // len = size of open interval (l, r)
            for (int l = 1; l + len - 1 <= n; l++) {
                int r = l + len - 1;
                for (int k = l; k <= r; k++) {          // k = LAST balloon burst in (l-1, r+1)
                    int coins = balloons[l - 1] * balloons[k] * balloons[r + 1]
                                + dp[l][k - 1] + dp[k + 1][r];
                    dp[l][r] = max(dp[l][r], coins);
                }
            }
        }
        return dp[1][n];
    }
};
```
**Time:** O(n³) **Space:** O(n²)

## 9. State Machine DP (Stock Trading)

*Trick: model each day as a small set of finite states (holding / not holding / cooldown) and transition between them.*

### 9.1 Best Time to Buy and Sell Stock with Cooldown
**LeetCode:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/

Maximize profit from unlimited transactions, but after selling you must skip one day before buying again.

**Approach:** Track three running states — `held` (holding a stock), `sold` (just sold today), `rest` (not holding, cooldown cleared).

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        if (prices.empty()) return 0;
        int held = INT_MIN, sold = 0, rest = 0;
        for (int price : prices) {
            int prevSold = sold;
            sold = held + price;             // sell today
            held = max(held, rest - price);  // keep holding or buy today
            rest = max(rest, prevSold);       // stay resting or come off cooldown
        }
        return max(sold, rest);
    }
};
```
**Time:** O(n) **Space:** O(1)

---

### 9.2 Best Time to Buy and Sell Stock III
**LeetCode:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock-iii/

Maximize profit with **at most two** buy-sell transactions (can't hold more than one share at a time).

**Approach:** Track four running states: best cost after 1st buy, best profit after 1st sell, best net after 2nd buy (reinvesting 1st profit), best profit after 2nd sell.

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int buy1 = INT_MIN, sell1 = 0, buy2 = INT_MIN, sell2 = 0;
        for (int price : prices) {
            buy1  = max(buy1, -price);         // best cost after 1st buy
            sell1 = max(sell1, buy1 + price);  // best profit after 1st sell
            buy2  = max(buy2, sell1 - price);  // best net after 2nd buy
            sell2 = max(sell2, buy2 + price);  // best profit after 2nd sell
        }
        return sell2;
    }
};
```
**Time:** O(n) **Space:** O(1)
